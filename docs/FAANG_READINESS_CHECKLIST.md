# Portfolio Readiness Checklist

- Real Kaggle dataset replaces simulated data.
- Multi-table feature engineering from application, bureau, and previous applications.
- Data dictionary acknowledged and documented.
- Data validation report covers schema, class balance, missingness, join coverage, and leakage guardrails.
- Training compares multiple candidate models.
- Evaluation reports ROC-AUC, average precision, Brier score, and confusion matrix.
- Interpretability artifact uses permutation importance.
- FastAPI app exposes single and batch scoring.
- Dockerfile and GitHub Actions CI are included.
- Tests cover feature engineering, joins, validation, prediction alignment, and API contracts.
