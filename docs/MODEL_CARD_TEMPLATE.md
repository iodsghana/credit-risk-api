# Model Card Template: Home Credit Default Risk

This file documents the report generated by `python src/train.py`. The generated version is written to `monitoring/model_card.md`.

## Intended Use

Estimate default probability for Home Credit loan applications using application, bureau, and prior-application history.

## Metrics Reported

- ROC-AUC for ranking quality.
- Average precision for rare-default performance.
- Brier score for probability quality.
- Confusion matrix at a 0.50 threshold.
- Top permutation importances for interpretability.

## Governance Notes

- `TARGET` is never included as a feature.
- `SK_ID_CURR` is only a join key.
- Predictions are model outputs, not automated lending decisions.
